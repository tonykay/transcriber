Transcriber output-directory options

Transcriber converts DJI recordings into Obsidian-compatible Markdown through speech-to-text, Ollama formatting, dictionary correction, templates, intent routing, and optional project classification.

Added CLI options

# Override the workspace for one run
transcriber process --output-dir "~/Resources/OtherTranscripts"
transcriber process -o "./meeting notes"

# List built-in default destinations and exit
transcriber --list-output-dirs

The override changes [paths].base for one run, including .processing intermediates. It does not move existing data or save configuration. Relative intent targets follow the new base; custom absolute targets remain unchanged.

The listing ignores user configuration, creates nothing, and separately labels output directories, append files, and processing directories.

For a permanent workspace shared by process, reprocess, and classify, set [paths].base in TOML. transcriber config shows the configured base.

Built-in layout

Under ~/Resources/Transcripts:

  • transcripts/: formatted transcripts
  • projects/: optional classification output
  • article-ideas/, blogs/: individual intent documents
  • todos.md, notes.md: append files
  • .processing/audio-unprocessed/, .processing/audio-processed/: audio intermediates
  • .processing/text-unprocessed/, .processing/text-processed/: text intermediates
